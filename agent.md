This is a TMS Project ( transport Management system) 
Stack : Quasar2, Netsjs, Sequeliz-typescript orm, Postgress database

Rules: use Quasar and Nestjs Standard practices. Try to use quasar components and clases instead defining css unless nessasary.

Right now we have no production database so you can wipe databse and resync to save migraiton issues. and you should seed default users etc if required.

If required you can read documentation and install npm packages and setup if required. 

Keep project modular and component based, do not make long files instead devide them in smaller logical units as best practises. Try to use Typescript Generics where possible and try to make resuable composibles and components
